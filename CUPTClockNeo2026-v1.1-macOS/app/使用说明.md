# CUPTClockNeo 2026 · 使用说明

SYSUPT 2026 校赛现场计时台。替代 2013 年的 clock 1.20，保留全部原有功能，重做了赛程逻辑、界面与稳定性。

---

## 一、两分钟上手

1. 打开 `CUPTClockNeo2026-v1.1-win64` 文件夹，双击 `CUPTClockNeo2026-v1.1.exe`。
2. 点右上角 **展示窗**，把新窗口拖到投影屏，按 `F11` 全屏。
3. 点 **开始**（或按空格），倒计时开始。
4. 一个环节结束，按 **下一环节**（或 Enter），下一项自动开始。

> **整个 `CUPTClockNeo2026-v1.1-win64` 文件夹要一起拷贝**，只拷 exe 跑不起来。不需要安装。
>
> 临时借用别人的电脑，直接拷 `CUPTClockNeo2026-v1.1.html` 这一个文件，双击用 Edge / Chrome 打开，功能完全一样。

## 二、界面结构

```
┌ 顶栏  轮次 第一轮  阶段 第 1 阶段  教室 325  题目 15 冰镇冷饮  [展示窗][对阵表][记录][说明][设置]
├──────────────────────────────────────────────┬───────────┐
│ 正方：A · 反方：B · 评论：C         ● 就绪     │  本阶段    │
│ 挑战与回应                                    │  12 个环节 │
│                                               │  列表      │
│ 01:00                                   ○     ├───────────┤
│ 剩余时间                                      │  快捷键    │
│                        [开始][下一环节][+1 分钟]│           │
│ ─────────────────────────────────────────     │           │
│ 下一环节 正方准备 01:00            16:14:51    │           │
└──────────────────────────────────────────────┴───────────┘
```

- **顶栏四段**：轮次 / 阶段 / 教室 / 题目，都是当前场次，点一下打开对阵表。
- **主区**：和展示窗**同一套版式**——左上队伍行、大标题，左下巨大倒计时，右侧进度环，右上一枚状态徽章，底部一条细线隔着「下一环节 + 当前时间」。单屏直接投出去就是一块赛场计时牌。
- **右栏**：本阶段 12 个环节列表（点任意一行直接跳过去），底部是快捷键提示。

### 屏幕要求

按**横屏**设计。宽度 ≥ 900px 时三栏完整显示；更窄的横屏会自动收窄顶栏、把右栏收成右下角「流程」浮钮（点开是抽屉，选完自动收起）；手机竖屏会显示「请横屏使用」的提示，不会硬塞。

分辨率本身不敏感——界面按 CSS 像素等比缩放，1080p、1440p、4K 显示器看到的比例是一样的，只是整体更大。真正决定观感的是**屏幕的 CSS 宽度和高度**（4K 显示器如果开了 150% 缩放，CSS 尺寸相当于 2560×1440，依然宽裕）。

### 快捷键

| 按键 | 作用 |
|---|---|
| `空格` | 开始 / 暂停 / 继续 |
| `Enter` | 结束本环节，进入下一环节（并按设置自动开始） |
| `Ctrl + Z` | 撤销上一步（切项、补时、重置都能撤） |
| `+` / `=` | 本环节补 1 分钟 |
| `Esc` | 关闭面板 / 退出全屏 |

> **展示窗里也能按键**：投影那个窗口获得焦点时，空格 / Enter / Ctrl+Z / + 照样有效，命令会转发回控制台执行，志愿者不用来回切窗口。底部会闪一行「已发送：…」确认。
>
> 前提是展示窗由控制台的 **展示窗** 按钮打开（这样两个窗口之间才有通道）；单独双击 html 再用 `?display=1` 打开的那个窗口没有通道，按键不起作用。
>
> 旧版把「开始」和「停止」绑在同一个空格上，误触一次就把表归零。新版空格只负责开始和暂停，结束必须是 Enter，而且每步都能撤销。

## 三、三支队伍 / 四支队伍

**设置 → 同一轮内比赛分组**：

- **三支队伍**：正方 / 反方 / 评论，一轮 3 个阶段
- **四支队伍**：正方 / 反方 / 评论 / 观摩，一轮 4 个阶段

切换后，对阵表的队伍列和角色轮换会同步改变，**计时流程完全不受影响**（每个阶段仍是 13 项、50 分钟）。

角色轮换按赛事手册表 1：

| 三支队伍 | 队 1 | 队 2 | 队 3 |
|---|---|---|---|
| 第 1 阶段 | 正方 | 反方 | 评论 |
| 第 2 阶段 | 评论 | 正方 | 反方 |
| 第 3 阶段 | 反方 | 评论 | 正方 |

| 四支队伍 | 队 1 | 队 2 | 队 3 | 队 4 |
|---|---|---|---|---|
| 第 1 阶段 | 正方 | 反方 | 评论 | 观摩 |
| 第 2 阶段 | 观摩 | 正方 | 反方 | 评论 |
| 第 3 阶段 | 评论 | 观摩 | 正方 | 反方 |
| 第 4 阶段 | 反方 | 评论 | 观摩 | 正方 |

决赛场次同样适用：在「轮次」选决赛，分组照常切换。

## 四、切换场次

点顶栏中间任意位置，或点 **对阵表**：

- **轮次**：第一轮 / 第二轮 / 第三轮 / 决赛
- **阶段**：第 1 / 2 / 3 /（第 4）阶段 / **决赛** / **自定义**
  - 选「自定义」后可以在「显示名称」里随便写，比如「半决赛」「决赛第一场」
  - 阶段决定角色怎么轮换，显示名称只影响屏幕上的文字
- **教室**：默认 325，下拉里还有 6501 / 6505 / 6506 / 6507，也可以**直接输入**任意教室名（比如「东 301」），自己输入的教室会被记住
- **本阶段题目**：从题库里选一道，选完立刻显示在顶栏

改完点 **应用**，顶栏、主区和展示屏一起更新。

### 队伍代号

面板中间「本场队伍」四行，每行填一个队伍代号（A–L）。四支队伍时第四行是观摩方。

代号留空就显示「待定」，决赛赛前直接填代号即可。

### 队伍名称

面板下方 12 个输入框，把 A–L 改成真实队名。改完顶栏和展示屏会显示队名（超过 10 个字会省略）。

## 五、题目与题库

内置 2026 年开放的全部九道题：

```
1  Invent yourself: Pinhole sunglasses  自我发明：针孔太阳镜
3  Snail ball                          蜗牛球
5  Y-shaped pendulum                   Y 形摆
8  Upward-driven disc                  上驱圆盘
9  Photographic bokeh                  摄影散景
12 Dotted line trick                   点线现象
15 Cold drink                          冰镇冷饮
16 Magnetic carousel                   磁力旋转木马
17 Falling book cover                  下落的书封
```

**导入自己的题库**：对阵表面板 → 题库 → 导入题库，文件选 `.txt` 或 `.csv`（UTF-8 编码），每行一题，下面三种写法任选其一：

```
15|Cold drink|冰镇冷饮      三列：编号、英文名、中文名
Cold drink|冰镇冷饮         两列：英文名、中文名，编号自动补
冰镇冷饮                    一列：只有中文名，英文名同中文
```

每行用竖线、Tab 或英文逗号分开都行，一份文件里统一用一种即可。导入是**追加**，与已有题目重复的自动跳过；导完在「本阶段题目」下拉里就能选到。点「恢复默认题库」退回默认九题。

题目按「轮次 + 阶段 + 教室」分别记录，换场次会各自记住自己选过的题。

## 六、反方报告的时间怎样自动流进讨论

这是 2026 赛制里唯一需要特殊处理的地方：反方报告最多 3 分钟，讲完剩下的时间归讨论。

程序把它做成**一个 13 分钟的容器**，3 分钟只是显示上的分界：

| 情形 | 屏幕显示 | 讨论实得 |
|---|---|---|
| 反方讲满 3 分钟 | 自动从「反方报告」切到「正反讨论」 | 10:00 |
| 反方 2 分钟讲完，按「进入讨论」 | 立即切换 | 11:00 |
| 反方 2 分钟讲完，不按 | 3 分钟到点自动切换 | 11:00 |
| 反方超时讲到 4 分钟 | 自动切换 | 9:00（自动扣） |

**志愿者一个键都不用按**，数字永远等于「13:00 − 已用时间」。

## 七、记录与导出

每结束一个环节自动记一条：时间、场次、环节、计划时长、实际用时、超时多少。

点 **记录 → 导出 CSV**，得到一份 Excel 可直接打开的表格（带 BOM，中文不乱码）。赛后复盘、处理时间争议都用得上。

记录存在本机，换电脑不同步；清理浏览器数据会清掉记录，重要场次请随手导出。

## 八、设置

- **同一轮内比赛分组**：三支 / 四支队伍
- **进入下一环节后**：默认自动开始计时，也可改成「停在待开始，等我按空格」
- **倒数提示音**：剩余 10 秒、5 秒、归零时各响一次，超时后每 10 秒提醒一次
- **音量**：0–1

> 浏览器规定页面必须先有一次点击才允许播放声音。打开页面后随便点一下按钮，提示音才会生效。建议赛前在 **设置 → 试听提示音** 里确认一次。

## 九、赛前检查清单

- [ ] 双击打开，顶栏轮次 / 阶段 / 教室对不对
- [ ] 分组选的是三支还是四支队伍
- [ ] 点开对阵表，把本场队伍代号填好，队伍名称改成真实队名
- [ ] 选好本阶段题目，确认顶栏显示正确
- [ ] 点 **展示窗**，拖到投影，`F11` 全屏，确认字够大
- [ ] 点一下按钮，再点「试听提示音」，确认音响有声
- [ ] 试跑一遍：按 Enter 走完两三个环节，确认切换正常
- [ ] 按 `Ctrl + Z` 试试撤销
- [ ] 收工前导出一次 CSV

## 十、出问题怎么办

| 现象 | 处理 |
|---|---|
| 双击 exe 弹出蓝色「Windows 已保护你的电脑」 | 未签名程序的例行提示。点「更多信息」→「仍要运行」，之后不再提示 |
| 杀毒软件报风险 | 绿色版 Electron 程序偶发误报，加信任即可，或改用 html 版 |
| 点「展示窗」没反应 | 浏览器拦了弹窗。地址栏右侧允许弹窗后重试 |
| 展示窗显示「等待控制台连接」 | 关掉展示窗，回控制台重新点「展示窗」 |
| 展示窗数字不走了 | 控制台窗口可能被最小化。点回控制台即可 |
| 展示窗里按键没反应 | 展示窗必须从控制台的「展示窗」按钮打开；自己单独开一个 `?display=1` 的窗口没有控制通道 |
| 没声音 | 先点一下页面任意按钮，再检查设置里的音量和系统音量 |
| 数字变红闪烁 | 已超时，显示的是超出时间。按 Enter 进入下一环节 |
| 右栏不见了 | 窗口太窄（< 900px），右栏收进了右下角「流程」按钮，点它滑出 |
| 手机上显示「请横屏使用」 | 正常，这个界面按横屏设计，把手机横过来即可 |
| 按错了 | `Ctrl + Z` 撤销。切项、补时、重置都能撤 |
| 页面被误关 | 重新打开，记录还在，当前计时会丢，从当前环节重新开始 |
| 上面都没解决 | 提 [GitHub Issue](https://github.com/azimiaojonsie/CUPTClockNeo2026/issues)，写明版本号、平台与复现步骤 |

## 十一、与旧版 clock 1.20 的差异

| 项目 | 旧版（2013） | 新版 |
|---|---|---|
| 运行环境 | Python 2.7 + Tkinter，仅 32 位 Windows | 单个 HTML / 免安装 exe |
| 计时内核 | 后台线程 `sleep(0.1)` 轮询，误差累积 | 绝对时间戳 + rAF，不漂移 |
| 线程安全 | Tk 控件在子线程里改，会崩 | 单线程状态机，非法转移直接拒绝 |
| 空格键 | 同时是开始和停止，误触归零 | 只做开始/暂停，结束归 Enter |
| 撤销 | 无 | 支持 |
| 反方报告 | 第三列手写 add to next，估算 | 13 分钟容器，恒等式计算，全自动 |
| 队伍数 | 固定三支 | 三支 / 四支可切换 |
| 赛事上下文 | 无，标题手写进 txt | 内置 2026 对阵表、角色轮换、题目库 |
| 教室 | 固定四个 | 可选可输入 |
| 记录 | 无 | 自动落盘 + CSV 导出 |
| 提示音 | 无 | 10 秒 / 5 秒 / 归零 / 超时 |
