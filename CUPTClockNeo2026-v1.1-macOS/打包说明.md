# macOS 版 · 打包说明

这个目录不是成品 app，而是**在 Mac 上一键生成 app** 的构建包。整个文件夹拷到 Mac 上，双击脚本，一分钟出结果。

## 用法

1. 把整个 `CUPTClockNeo2026-v1.1-macOS` 文件夹拷到 Mac
2. 双击 `双击打包.command`
   - 若提示「无法打开，因为来自身份不明的开发者」→ 右键点它 → 选「打开」
   - 或在终端里：`chmod +x 双击打包.command && ./双击打包.command`
3. 首次运行会联网下载 Electron 运行时（约 115 MB），之后不再需要网络
4. 跑完当前目录会出现 `CUPTClockNeo2026-v1.1.app`

## 为什么不在 Windows 上直接给成品 app

三个原因，都不是配置问题：

1. **符号链接**：macOS 的 `.app` 里，framework 目录用 14 处符号链接组织（`Versions/Current → A` 之类）。Windows 没有创建符号链接的权限，强行复制成实体文件会把 115 MB 撑到 750 MB，而且结构不可靠。
2. **签名**：macOS 应用要用 `codesign` 签名，这一步只能在 Mac 上执行。
3. **公证**：正式分发还要 `notarytool` 提交苹果公证，同样只能在 Mac 上做。

所以在 Mac 上跑一次脚本，比在 Windows 上硬拼一个可疑的包更靠谱。

## 首次打开

脚本最后已经执行了 `xattr -cr` 解除隔离标记，正常情况下双击即可。若仍被拦：

- 右键点击 app → 打开 → 再点「打开」
- 或终端：`xattr -cr /Applications/CUPTClockNeo2026-v1.1.app`

## 如果要正式分发

有 Apple Developer 账号的话，在 Mac 上：

```bash
codesign --deep --force --options runtime \
  --sign "Developer ID Application: 你的名字 (TEAMID)" \
  CUPTClockNeo2026-v1.1.app

ditto -c -k --keepParent CUPTClockNeo2026-v1.1.app CUPTClockNeo2026.zip
xcrun notarytool submit CUPTClockNeo2026.zip --apple-id 你的邮箱 --team-id TEAMID --wait
xcrun stapler staple CUPTClockNeo2026-v1.1.app
```

```
└── app/               程序本体，与 Windows 版是同一份 HTML
    ├── main.js
    ├── package.json
    ├── CUPTClockNeo2026-v1.1.html
    ├── 使用说明.md
    └── 赛程预设-2026.json
```

功能与 Windows 版完全一致：双窗口（控制台 + 展示窗）、快捷键、展示窗遥控、记录导出、三/四队切换都在。macOS 上窗口全屏快捷键是 `⌃⌘F`。
